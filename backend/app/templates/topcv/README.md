# TopCV source templates

Only the nine compatibility layouts still rendered by `topcv_renderer.py` retain HTML/CSS here. The fifteen layouts replaced by supplied PDFs use the reference renderer modules instead; their superseded HTML/CSS has been removed. `sources.json` retains all stable IDs and original provenance. Do not remove the compatibility layouts while saved CVs can still reference them.

These fragments and styles were downloaded from the public TopCV preview pages requested by the project owner. `sources.json` records the original names, template slugs, source URLs, preview URLs and checksums of the stored files.

The HTML retains the original layout and row prototypes. Demo content, scripts, tracking, remote avatar images and unsupported demo sections were removed. The renderer fills the fragments with CVDocument data and adapts pagination, missing fields, projects and inline skill groups. Styles and embedded assets come from the public source stylesheets. These are not the hand-built layouts from the previous implementation.

The six groups are application navigation groups, four layouts each; they are not a claim that TopCV assigns exactly the same categories. Local IDs remain aliases for existing saved CVs. The templates use HTML/CSS; no original TopCV LaTeX source is claimed or supplied. TopCV and asset authors retain their respective rights and notices.
